# State & Emotion Mappings

The narrative state is a visual organization state, not a diagnosis.

## State Definitions

| State | Core condition | Organization | Ownership |
|---|---|---|---|
| baseline | stable default | medium-high | world / shared |
| pressure | external force narrows options | medium | contested |
| crisis | character-specific visual logic fails | low | external / unstable |
| decision | one choice becomes clear | rising | in transfer |
| agency | character controls primary variable | high | character |
| resolution | new stable baseline with residue | high | negotiated / character-led |

## Default Emotion Routing

Use this only when the user has not specified a state.

| Visible / requested tone | Default state | Notes |
|---|---|---|
| calm | baseline | keep visual range restrained |
| hopeful | resolution / agency | use agency only if body/gaze supports outward intent |
| curious | baseline / mild pressure | focus_attention often suitable |
| lonely | pressure | do not automatically imply crisis |
| vulnerable | pressure | boundary_emotion often suitable |
| tense | pressure | increase constraint, not random chaos |
| pressured | pressure | external organization should be visible |
| conflicted | pressure / crisis | crisis only if visual contradiction is strong |
| overwhelmed | crisis | reduce hierarchy reliability; preserve identity anchors |
| rebellious | decision / agency | rebellion_time often suitable |
| determined | decision | one direction / boundary / focal choice becomes clear |
| awakened | agency | ownership change should be visible |
| intimate | baseline / resolution | use shared space or permeability rather than spectacle |

## Confidence Rule

Emotion inference must include confidence:
- **high:** expression, pose, gaze and composition converge.
- **medium:** two or more visible signals align.
- **low:** expression is neutral or signals conflict.

At low confidence, do not invent dramatic psychology. Let composition drive the visual plan.

## State Transformation Rules

### Baseline
- preserve source framing most strongly
- medium stylization is permitted but hierarchy remains stable
- background still behaves as an environment rather than a symbolic field

### Pressure
- narrow range of the archetype’s primary variable
- increase world/system influence
- add directional, edge, focus, or temporal resistance depending on archetype
- preserve a clear fallback readability channel

### Crisis
- break the **character-specific** rule, not all rules
- reduce visual organization while preserving 2–3 identity anchors
- avoid simply setting all intensity values to maximum

### Decision
- lower noise
- isolate one choice
- use Visual Silence where useful
- camera often becomes neutral witness before it becomes aligned

### Agency
- restore organization under character control
- allow camera allegiance to move toward character
- increase ownership rather than raw spectacle
- use Predictive Framing for path_space when appropriate

### Resolution
- form Baseline B
- preserve residue from the conflict: color, edge, texture, spatial habit, or framing
- do not simply return to original visual defaults

## Four-State Sheet Standard

Default four-panel sequence:

`baseline → pressure → crisis → agency`

Identity anchors must remain constant. At least two of the following must change structurally across panels:
- camera relationship
- space / focus ownership
- edge hierarchy
- color territory
- information density
- temporal / medium synchronization

Palette-only differentiation fails the test.
