01

Character Visual System

Identity is a controlled range.

不要用服装或色板定义角色。先找到一个承担叙事的 Primary Variable，再定义什么永远不变、何时失效，以及角色如何夺回控制权。

Character Bible 不回答“长什么样”，而回答“在压力下，哪些变量变化、哪些不变”。

01.1 / State machine

压力不是换皮肤，而是规则变形

选择一个状态，观察 Focus / Visibility 角色的主变量、摄影机和可读性如何一起变化。

01.2 / Character architecture

一个角色，四层渲染优先级

  1. Level 1Identity Anchor

    剪影、明度骨架、姿态家族或时间签名。跨世界仍须保留。

  2. Level 2Primary Narrative Variable

    Space、Edge、Time 或 Focus。只允许一个变量领奏。

  3. Level 3State-sensitive Variables

    在压力、危机、决定和 Agency 中有条件地变化。

  4. Level 4Surface Enrichment

    材质、细节与效果必须服从前三层，永远不能遮蔽结构。

SPACE × SHAPE

Miles-type

危机是路径选择坍缩；Agency 是创造路线，而非跟随路线。

EDGE × COLOR

Gwen-type

危机是边缘层级不再对应情感重要性；Agency 是选择边界。

TIME × MEDIUM

Hobie-type

危机是被迫统一和同步；Agency 是有意选择同步或不同步。

FOCUS × EDGE

Elian-type

危机是错误对象不断变清楚；Agency 是决定什么值得被看见。

Failure test

移除 Color、Texture、完整剪影或动态中的任一通道。若角色仍能通过至少三个独立通道被识别，身份才是结构性的。

02

World Visual Grammar

A world is a set of default behaviors.

先定义图像在这个世界里通常怎样生成，再决定角色在哪些维度顺从、放大、抵抗或改写它。

Large space does not necessarily mean freedom.

02.1 / Grammar

世界不是 Palette + Architecture

WORLDVisual
Grammar
ShapeSpaceValueColorEdgeMediumDensityCameraTime

World thesis first. 不从“水彩世界”或“赛博朋克世界”开始，而从“现实会被情绪渗透”或“注意力被制度管理”开始。

Selective deviation. 角色只在少数维度显著偏离世界。差异预算越明确，身份越可读。

Hybrid residue. 跨世界归来不是 A → B → A，而是保留旅程痕迹的 Baseline B。

03

Sequence Direction

Orchestrate variables, not noise.

Sequence 的最小单位是 Visual Beat：一个或多个视觉变量发生有意义的改变。高潮不是参数全满，而是叙事在控制权上汇聚。

Before designing a climax, ask: what can still change?

04

Color Direction

Color is behavior, not hue.

追踪颜色属于谁、占据多大区域、如何越过边界、何时靠近身份核心，以及事件结束后留下什么残余。

Physical boundary ≠ Color boundary.

颜色在画面中争夺领地

Keep the mechanism. Remove the surface.

Who decides what
deserves to be seen?

一个不依赖 Spider-Man、黑红、水彩或朋克拼贴的原创案例。只保留生成机制：Focus / Visibility 与 Ownership Conflict。

Elian is an Attention Character.

COUPLED PAIRFocus × Edge

Elian 的核心问题不是移动自由，而是感知自主。三角肩部轮廓、右眼浅色 Mark 和持续前倾的 Search Wedge 构成跨世界稳定锚点。

06.2 / World thesis

Meridian manages attention to preserve order.

漏斗式 Shape Grammar 把道路、建筑、灯光和标识导向预定目标。几何空间很深，但感知深度被人为排序。

Geometric Depth ≠ Perceptual Depth

从 Assigned Vision 到 Rewrite

  1. 01Assigned vision接受系统焦点
  2. 02Forbidden detail注意未被突出之物

06.4 / Constraint tests

效果被禁用，机制仍成立

NO BLUR

NO AMBER

用 Hierarchy 和 Contrast Assignment 继续表达所有权。

MONOCHROME

用边缘与明度优先级表达被看见与被压制。

MOTION ONLY

身体从外部牵引转向主动锁定，仍可读出 Agency。

Field Tool / W

Master Workflow

从 Brief 到 Final Sequence 的 20 步生产路径，按四个阶段组织。选择阶段查看工作目标与交付门槛。

PHASE 01 / STEPS 01—05

Define the narrative engine

先把故事问题压缩成一个可视化的行动逻辑，不讨论风格标签。

  1. 01
    Narrative Situation

    写发生什么，而不是画面长什么样。

  2. 02
    Character State

    定义人物现在处于什么心理位置。

  3. 03
    Viewer Response

    观众第一时间应该感受到什么。

  4. 04
    Narrative Verb

    压缩成 CLAIM、WITHDRAW、DIVIDE 或 REFOCUS。

  5. 05
    Core Loss

    找到角色最怕失去的能力或关系。
