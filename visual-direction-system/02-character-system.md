# 02｜Character Visual System

## Character thesis

Define each character in one visual sentence, not by costume or palette.

Examples of mechanism-level theses:

- **Miles-type:** identity autonomy is expressed through control of space and movement direction.
- **Gwen-type:** relationship and emotion are expressed through hard, soft, and lost boundaries.
- **Hobie-type:** autonomy is expressed through selective synchronization and medium independence.
- **Elian-type:** autonomy is expressed through deciding what deserves attention.

## Character system structure

```text
Character Thesis
→ Primary Variable
→ Stable Anchors
→ Coupled Variable Pair
→ Readability Ladder
→ Temporal Signature
→ State Machine
→ Camera Relationship
→ Break Conditions
```

## Stable identity anchors

Choose 2–3 features that survive world, lighting, palette, and medium changes. Strong anchors may include silhouette, value skeleton, gesture family, recurring directional bias, temporal signature, or a simple graphic mark.

## Coupled variable pairs

A character often becomes coherent when two variables are linked:

| Character mechanism | Coupled pair |
|---|---|
| Space-driven | Space × Shape |
| Boundary-driven | Edge × Color |
| Rule-driven | Time × Medium |
| Attention-driven | Focus × Edge |

Pairs can be **coupled**, **opposed**, or **independent**. Deliberate opposition is especially useful for drama.

## Readability ladder

Define backup recognition channels. Example:

```text
1. Silhouette
2. Direction
3. Value
4. Color
5. Motion
```

When one channel fails, another should compensate. If a dark character enters a dark environment, strengthen direction, negative space, motion contrast, or accent marks rather than automatically brightening the character.

## Character-specific crisis

A visual crisis should disable the character's own visual capability.

- Space-driven character: path ownership collapses.
- Boundary-driven character: edge hierarchy becomes contradictory.
- Time-driven character: forced uniformity removes meaningful difference.
- Attention-driven character: the wrong things become visually dominant.

This is stronger than generic darkness, blur, or noise.

## Character-specific agency

Agency means the character begins controlling the primary variable.

| Primary variable | Agency sign |
|---|---|
| Space | creates routes rather than follows them |
| Boundary | chooses where to be hard, soft, open, or lost |
| Time / Medium | chooses when to synchronize or diverge |
| Focus | chooses what becomes perceptually important |

## Miles-type system

**Primary:** Space / Direction  
**Anchors:** dark mass, clear accent mark, compact↔elastic gesture range  
**Crisis:** movement range and path choice collapse  
**Agency:** environment and camera begin anticipating the character's chosen path  
**Climax:** spatial expansion after compression

## Gwen-type system

**Primary:** Boundary / Edge  
**Anchors:** ribbon-like gesture, black-white value structure, selective edge clarity  
**Crisis:** hard/soft/lost hierarchy no longer corresponds to emotional importance  
**Agency:** selective boundary ownership returns  
**Climax:** representation is reduced until the relationship boundary becomes clear

## Hobie-type system

**Primary:** Time / Medium  
**Anchors:** stable dark skeleton, clear silhouette, coherent global gesture  
**Crisis:** excessive normalization and synchronization  
**Agency:** intentional sync and desync become equally available choices  
**Climax:** rule reversal rather than simple increase in chaos

## Integrated rendering hierarchy

```text
LEVEL 1 — Identity Anchor
LEVEL 2 — Primary Narrative Variable
LEVEL 3 — State-sensitive Variables
LEVEL 4 — Surface Enrichment
```

The lower levels must never obscure the upper levels.

## Failure test

Remove one channel at a time:

- no color;
- no texture;
- silhouette only;
- motion only;
- edge behavior only.

If the character remains recognizable through at least three independent channels, the system has structural identity rather than surface dependence.
