## 1. Post-event recovery is structural, not a palette reset

### OBSERVED

`B009-001–004` continue directly after the graphic explosion override. Officers, vehicles, faces and the institutional grouping regain clear structural readability. At the same time, source-local magenta/cyan emergency illumination remains active.

### INFERRED

Recovery does not mean “return to neutral color.” What recovers is the base scene's **structural authority**: figure separation, object specificity, institutional staging and normal detail allocation.

### GENERATIVE RULE

```text
event override
→ recover structure / detail / choreography
→ decide which source lights and residues persist independently
```

Add: `post_event_detail_reentry`, `recovery_structure_level`, `residual_source_light_hold`.

## 2. Action Signature Before Body Reveal

### OBSERVED

From `B009-005` onward, a white web trajectory enters the police scene while Gwen's body remains off-screen. The web progressively changes officer states and binds the group. Gwen's body is not explicitly revealed until `B009-015`.

### INFERRED

A character can enter a sequence first as **agency**, not as body. The audience reads a recognizable action material/motion signature before visual confirmation of the actor.

### GENERATIVE RULE

```text
off-screen action signature
→ scene-state change
→ material consequence
→ reveal delay
→ body reveal payoff
```

Add: `action_signature_before_body_reveal`, `offscreen_action_identity`, `body_reveal_delay`, `signature_to_body_handoff`.

Do not automatically announce an entrance with global FX or immediate face exposure if the action signature already carries identity.

## 3. Persistent Diegetic Graphic Material ≠ Local Comic Punctuation

### OBSERVED

`B009-007–014` show the web first as trajectory, then as persistent patches and a depth-spanning network attached to officers and scene elements. The material remains after the initiating motion has ended.

### INFERRED

Comic-like linework belongs to more than one ontological class:

```text
Transient Graphic Notation
≠
Persistent Diegetic Graphic Material
```

Earlier fingertip/radio/contact marks are event-local punctuation. The web here is materially causal: it attaches, accumulates, occludes, spans depth and restrains bodies.

### GENERATIVE RULE

For persistent graphic materials, model attachment target, accumulation, depth plane, occlusion, tension/curve, material consequence and persistence duration.

Add: `persistent_graphic_material`, `constraint_geometry`, `material_trajectory_role`, `depth_spanning_line_network`.

**Hard failure:** treating all graphic lines as transient screen-space FX.

### INFERRED

The entrance is carried by inversion + extreme foreground scale + hood/mask geometry + costume mass + prior web signature.

### GENERATIVE RULE

## 5. Search-state Information Withholding

### OBSERVED

After Gwen leaves the police tableau, `B009-018–024` move into smoke and then an obscured Guggenheim interior. Explicit architectural/object detail falls sharply. This happens after peak-speed action has already decreased.

### INFERRED

Reality/Detail Suppression is not driven only by emotional intensity or high velocity. It can also be driven by **perceptual uncertainty**. Gwen does not yet possess reliable information about the threat-space, so the image withholds information from the viewer as well.

The broader model becomes:

```text
Narrative / Perceptual Demand
→ Description Density
```

rather than `World Name → Fixed Detail Level`.

### GENERATIVE RULE

Add: `search_state_information_budget`, `uncertainty_detail_suppression`, `threat_space_obscuration`.

When the narrative problem is search/uncertainty, preserve enough spatial anchors for orientation while suppressing facts the character/viewer should not yet own.

## 6. Lighting Ownership Handoff at a spatial threshold

### OBSERVED

The police exterior is organized by explicit emergency sources: sirens, headlights and spotlights. As Gwen enters the smoke/interior threshold, those source-local territories disappear and broad magenta/blue, then blue/teal/green atmospheric fields take over.

### INFERRED

A transition may hand color/light ownership from explicit diegetic source → event residue/atmosphere → world field without treating the cut as a fresh palette selection.

### GENERATIVE RULE

Add: `lighting_ownership_handoff`, `threshold_color_field_transition`, `source_to_atmosphere_transfer`.

## 7. World Authority Scale Transfer

### OBSERVED

Within this batch Gwen moves from an enormous inverted foreground reveal to a tiny silhouette in `B009-024`, surrounded by an enormous low-information blue-green field.

### INFERRED

Subject scale itself can be an authorship variable. Shrinking the protagonist transfers visual authority to the unknown environment.

### GENERATIVE RULE

```text
character authority
→ subject scale collapse
→ negative-space expansion
→ world / threat authority
```

Add: `world_authority_scale_transfer`, `subject_scale_collapse`, `environmental_dominance_peak`.
