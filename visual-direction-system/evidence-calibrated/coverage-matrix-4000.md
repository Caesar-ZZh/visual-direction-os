# 4000-Frame Evidence Coverage Matrix

## Purpose

The research target is an approximately **4,000-frame high-coverage evidence corpus**, not a mechanical pass over every screenshot. A frame counts only when its actual image is visually opened and receives at least L1 distillation. The corpus is multi-label: one frame may support several chapters.

## Selection priority

```text

→ representative frame
→ transition/change-point frame
→ counterexample
→ sequence continuity support
→ deep diagnostic
```

Near-duplicates enter only when they contribute temporal, micro-performance, held-channel, transition, representative or counterexample evidence.

## Batch rules under the 4,000-frame strategy

Each batch must answer:

1. **What existing GitHub chapter(s) does this evidence strengthen?**
2. **What prior assumption does it validate, narrow, revise, or contradict?**
3. **What production / Skill parameter follows from the evidence?**
4. **What coverage gap should influence later sampling?**

## Evidence levels

- **L1** — selected source frame actually opened + minimum structural annotation.
- **L2** — change point / representative / counterexample with mechanism analysis.
- **L3 / Deep** — diagnostic frame/sequence used to revise theory, workflow, prompt schema or QA.
