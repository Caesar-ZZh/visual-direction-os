# OBSERVED

## O-B002-01 — The room remains emotionally active after the character exits

At `B002-005`, the camera holds on the same painterly room after Gwen disappears. The palette does not neutralize and the room does not become more detailed. Because the visual field is held, the absence itself becomes the event.

This is stronger evidence than simply calling a sparse image “visual silence.” Here the silence is produced by **subtracting character presence while preserving visual memory**.

## O-B002-02 — Emotional close-ups can keep crisp facial description

`B002-006` and `B002-008–011` preserve readable eyes, brows, nose, mouth and face-plane structure. The world remains heavily chromatic and painterly, but the face is not globally dissolved into watercolor or lost edges.

This directly counters an overly broad application of:

```text
Emotion ↑ → Physical Description ↓
```

The relation is conditional, not universal.

## O-B002-03 — Warm/cool color is spatially assigned to relationship planes

In `B002-009–011`, Gwen occupies most of the frame in a blue-violet/teal field. George is much smaller and contained inside a bright warm yellow-orange doorway. The palette does not merely tint the whole image; it **partitions the relationship spatially**.

## O-B002-04 — The camera can stay locked while the beat advances

Across the wide shot, reaction close-up, and two-plane close-up, consecutive frames show very small camera changes. Progression often comes from walking, disappearance, eye opening, gaze shift and head movement.

## O-B002-05 — Environment and character do not share one uniform rendering density

Room furniture and architecture are often broad painted masses with suppressed edges/details. Character faces can remain comparatively crisp in the same sequence. This is direct evidence for **surface heterogeneity** rather than whole-image style filtering.

# INFERRED

## I-B002-01 — Earth-65 redistributes emotional load across channels

The world does not appear to obey a simple rule such as “more emotion = softer image.” Instead, emotion can be carried by different combinations of:

- color territory;
- subject scale;
- foreground/background separation;
- architectural framing;
- environmental detail suppression;
- edge hierarchy;
- gaze and micro-expression;
- character presence/absence.

A channel can remain stable while another channel takes over.

### Revised formula

```text
Emotional Load
→ choose carrier channel(s)
→ redistribute visual authority
→ preserve readability
```

not:

```text
Emotional Load
→ increase watercolor / blur / saturation / texture
```

## I-B002-02 — Doorways act as relational boundary devices

The doorway is not just location information. It works as:

- a geometric separator;
- a value boundary;
- a color territory boundary;
- a depth-plane container;
- later, a frame that contains George as the secondary relationship pole.

The same architectural element therefore carries space, color, depth and relationship simultaneously.

## I-B002-03 — Visual silence can preserve saturation

`B002-005` is emotionally quiet without being gray, empty-white or desaturated. The frame stays richly colored. Therefore visual silence should be defined by **event density and information change**, not by low saturation.

## I-B002-04 — Stable visual grammar can amplify performance

When camera, palette and medium stay fixed, a small change in eyes or head angle becomes proportionally more important. This suggests an important sequence rule:

> **Do not spend visual reserve when performance is already carrying the beat.**

# GENERATIVE RULES

## G-B002-01 — Character-removal silence

For a departure or emotional withdrawal beat:

```text
Establish character inside a strong environmental field
→ let the character cross a clear boundary
→ remove the character
→ hold the same camera and world field
→ allow negative space + color memory to become the beat
```

Do not automatically fade color or add symbolic effects.

## G-B002-02 — Relational two-plane staging

For emotionally distant but connected two-character scenes:

```text
Foreground Character A = dominant scale + one temperature field
Background Character B = reduced scale + bounded architectural field
Depth separator = doorway / corridor / frame-within-frame
Color territories = distinct but compositionally connected
Camera = stable
Performance = micro-expression / gaze
```

Texture should remain secondary.

## G-B002-03 — Variable-substitution emotional rendering

When emotion increases, choose **which** realism channel yields rather than degrading all of them.

Possible substitutions:

- keep face detail, suppress environment detail;
- keep edges, shift color ownership;
- keep palette, change scale/depth;
- keep camera, change gaze/performance;
- keep character rendering, remove the character and let environment carry residue.

## G-B002-04 — Surface heterogeneity is mandatory

Do not apply one global style treatment to:

- face;
- hair;
- clothing;
- architecture;
- doorway/light field;
- background props.

Each surface may receive a different detail/edge/texture policy while the image remains coherent through hierarchy and color territory.

# Corrections to the existing knowledge base

## Correction 1 — `Emotion ↑ → Physical Description ↓` must be scoped

The earlier rule remains useful as one **possible** Earth-65 behavior, especially in wide environmental frames, but it is not a universal law.

Revised:

> **Emotion ↑ → Visual description is redistributed. One or more physical-description channels may be suppressed, while protected channels remain crisp enough for character/beat readability.**

## Correction 2 — Gwen is not a “soft-edge character”

Gwen close-ups in this batch can be highly crisp. The more durable principle is:

> **Gwen/Earth-65 permits selective edge and detail redistribution according to relationship and emotional function.**

## Correction 3 — Color behavior is spatial, not just chromatic

The important observation in `B002-009` is not simply “cool Gwen / warm George.” It is that those colors occupy **different planes and bounded territories**. Color and composition are one system here.

# Skill calibration consequence

The image-generation Skill must stop using a fixed `boundary_emotion → watercolor + soft edge + pink/blue` translation.

It needs a carrier-selection stage:

```text
Narrative State
→ Emotional Carrier Selection
   ├─ composition / scale
   ├─ color territory
   ├─ edge redistribution
   ├─ detail suppression
   ├─ depth-plane separation
   ├─ character absence
   └─ micro-performance hold
→ rendering plan
```

A generated emotional close-up should **not** be penalized for keeping a crisp face if the relational mechanism is carried by color/depth/space instead.
