# 00 — Research Protocol

## Research question

How does *Across the Spider-Verse* construct visual meaning across character, world, narrative state, camera, color, edge, rendering, texture and time — and which of those mechanisms can be translated into reusable visual-direction rules without collapsing into a generic comic filter?

## Evidence discipline

Every statement must be tagged as one of:

| Type | Meaning |
|---|---|
| **OBSERVED** | Directly visible in the reviewed frame(s). |
| **INFERRED** | Interpretation supported by multiple frames or clusters. |
| **GENERATIVE RULE** | Production instruction derived from evidence. |

A useful theory is not automatically a film fact. A recurring palette is not automatically a world rule. A character's primary narrative variable is not the same thing as a fixed rendering style.

## Corpus workflow

### PASS A — Frame-by-Frame Census

Every source screenshot is visually reviewed. Minimum annotation covers:

- source / cluster identity;
- world and location;
- characters and relational dominance;
- narrative beat / state / visible emotion;
- shot size / angle / orientation / projection;
- composition / subject scale / depth / negative space / spatial pressure;
- shape / silhouette / value / lighting;
- Reality Suppression / Controlled Flattening / Detail Suppression / Line Strategy;
- edge hierarchy;
- color family / ownership / territory;
- texture / halftone / hatching / misregistration / glitch;
- temporal effect / motion energy;
- primary and secondary visual variables.

### PASS B — Cluster & Change-Point Analysis

Adjacent near-duplicate frames are still reviewed, but assigned to Shot / Scene Clusters. We explicitly mark:

- cuts and framing changes;
- foreground/background ownership shifts;
- scale and occlusion changes;
- color territory migration;
- hard/soft/lost edge redistribution;
- rendering-mode changes;
- world contamination / collision;
- temporal irregularity;
- visual silence;
- climax / ownership transfer.

### PASS C — Deep Visual Forensics

Diagnostic frames receive deep analysis in at least these domains:

1. Composition skeleton
2. Shape simplification
3. Value masses
4. Facial plane abstraction
5. Reality suppression
6. Controlled flattening
7. Depth suppression / exaggeration
8. Detail suppression
9. Line / contour / hatch strategy
10. Surface-specific texture assignment
11. Halftone placement
12. CMYK / print-registration behavior
13. Color ownership / territory / migration
14. Edge script
15. Camera allegiance
16. Readability substitution
17. Sequence function
18. Temporal signature
19. Counterexamples
20. Production / Skill translation

## Anti-bias rules

- Search for **counterexamples**, not only confirmation.
- Do not use a single iconic frame to define an entire character or world.
- Do not assume halftone, neon, watercolor, chromatic aberration or graffiti are universal identifiers.
- Do not infer camera movement from one still unless adjacent frames support it.
- Do not infer hidden psychology; distinguish visible emotion from narrative interpretation.
- Do not treat naturalistic object color as the baseline when the frame demonstrates psychological color.
- Do not duplicate all source images physically. Keep originals untouched; copy only diagnostic references into curated sets.

## Core failure test for generative translation

> **If color and surface FX are removed and the result still reads as generic realistic / AI-3D concept art, the Spider-Verse rendering translation has failed.**

A successful translation should survive through shape, value, composition, rendering construction, edge logic and camera behavior before decorative texture is added.

## Confidence policy

- `0.5–0.69`: tentative
- `0.70–0.84`: supported but local
- `0.85–0.94`: strong within multiple relevant examples
- `0.95+`: highly stable only after broad cross-scene validation

No scene-local inference should be described as a whole-film law regardless of numerical confidence.
