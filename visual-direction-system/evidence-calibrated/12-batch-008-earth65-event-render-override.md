## 1. Motion-state Detail Re-entry

`B007-019` had already shown that high-speed readability can improve when most environmental description is removed. `B008-001–003` continue the kinetic sequence, but as Gwen slows and reaches the rooftop the city begins to recover descriptive information. By `B008-008`, museum architecture, police vehicles, crowd hierarchy and location identity are again allowed to matter.

### OBSERVED

The amount of environmental description increases as the sequence moves from high-speed silhouette/trajectory reading toward observation and investigation.

### INFERRED

Detail budget is not only world-dependent. It is **motion-state dependent**. A coherent world can survive large changes in description density if the sequence preserves identity, direction, value hierarchy and color-field continuity.

### GENERATIVE RULE

```text
velocity/readability pressure ↑
→ environmental description ↓
→ silhouette / trajectory authority ↑

velocity/readability pressure ↓
→ detail re-entry allowed
→ location / institution / object specificity ↑
```

Add:

- `velocity_detail_budget`
- `detail_reentry_trigger`
- `world_detail_recovery`

Do not render every action frame at the same environmental detail level.

## 2. Contact-local punctuation remains local

At `B008-003`, Gwen lands into a handstand. Tiny cyan zigzag marks appear only at the two hand-contact points.

### OBSERVED

The graphic marks are much smaller than the figure and do not spread across the rooftop, body or city.

### INFERRED

This independently validates the earlier **Local Comic Punctuation** rule. Graphic notation can be attached to a physical event rather than used as a global comic filter.

### GENERATIVE RULE

Localize notation by:

```text
trigger event
→ target region
→ spatial radius
→ attack / hold / decay
```

The base world must remain valid after the notation is removed.

## 3. Diegetic Vector Light / Attention Funnel

`B008-004–007` are a particularly strong camera-composition sequence. Gwen faces the incident from a rooftop while helicopter spotlight cones converge toward the same lower target. As the camera moves closer to her back/head, the target remains legible through the combination of a saturated magenta hotspot and converging pale beams.

### OBSERVED

The sequence uses:

- Gwen's rear-facing orientation;
- target direction;
- two converging spotlight cones;
- strong value separation;
- a localized magenta incident hotspot;
- progressive subject enlargement.

### INFERRED

Diegetic lighting can perform the function that a weaker design might solve with UI arrows or non-diegetic graphic indicators.

### GENERATIVE RULE

Build an **Attention Funnel** as:

```text
Subject Orientation
+ Diegetic Vector Light
+ Target Contrast
+ Depth Direction
→ Attention Lock
```

Add:

- `diegetic_vector_light`
- `light_cone_target`
- `attention_funnel`

## 4. Source-owned Event Bloom

`B008-008–017` move into the Guggenheim police perimeter. Helicopter spots, headlights and sirens produce extreme white/cyan/magenta blooms and vertical streaks, but these effects remain attached to explicit sources.

### OBSERVED

A police car can contain near-white blown highlights while an officer's face, museum architecture, crowds and dark street zones remain structurally distinct elsewhere in the frame.

### INFERRED

The sequence is not using a generic neon-magenta/cyan world filter. It is using **source ownership**.

### GENERATIVE RULE

For every bloom/streak ask:

```text
What emits it?
Where is its region mask?
What direction does it travel?
What survives outside that source territory?
```

Add:

- `source_owned_bloom`
- `bloom_region_mask`
- `siren_streak_orientation`

**Hard failure:** whole-frame cyan/magenta glow without source logic.

At `B008-017`, the male PDNY officer/detective has crisp angular facial landmarks over broad magenta/red and cool-blue planes while the background crowd is compressed.

`B008-018–020` cut into an extreme close-up of a police dossier. A rough magenta-brown-dark-blue Vulture portrait is embedded inside crisp typed administrative paper.

### OBSERVED

Vulture image

### INFERRED — PROVISIONAL

## 7. Event Render Override is phase-based

`B008-021–024` gives a clean event sequence:

```text
BASE
B008-021 — officers / folder / emergency-light grammar

ATTACK
B008-022 — near-white luminance field + debris + impact shards

HOLD
B008-023 — flat graphic nested/scalloped plume grammar

RECOVERY
B008-024 — officers, vehicles and source-owned emergency light regain authority
```

### OBSERVED

The explosion does not merely add an effect on top of an unchanged base render. During the attack, most normal environmental description is temporarily surrendered. During the next phase, the smoke itself adopts a new graphic shape grammar. Then the base scene returns.

### INFERRED

Large narrative events can temporarily own the rendering system.

### GENERATIVE RULE

Add:

- `event_render_mode`
- `event_render_attack`
- `event_render_hold`
- `event_render_recovery`
- `base_grammar_recovery`

A major event should have a temporal rendering envelope, not just a static particle layer.

## 8. Explosion Cloud Shape Grammar

`B008-023` is the diagnostic frame. The smoke is not modeled primarily as smooth semi-transparent volumetric fog. It is organized into large dark brown-purple nested/scalloped lobes with cream/gold contour bands.

### OBSERVED

Readability comes from:

- discrete lobe hierarchy;
- flat value groups;
- nested contour rhythm;
- high-authority outer and inner edges;
- controlled gaps between forms;
- selective interaction with debris and the recovering street.

### GENERATIVE RULE

Treat graphic smoke as a shape-design problem before a simulation problem:

```text
plume silhouette
→ lobe scale hierarchy
→ nested contour rhythm
→ value grouping
→ edge mode
→ debris integration
```

Add:

- `explosion_cloud_shape_grammar`
- `plume_lobe_scale`
- `graphic_smoke_edge_mode`

**Hard failure:** default soft photoreal volumetric smoke when the intended event grammar is graphic/shape-led.

## New hard failures

Fail and re-plan when:

1. emergency cyan/magenta bloom is spread globally instead of assigned to actual sources;
2. environment detail remains equally dense through every velocity state;
3. UI arrows/graphic indicators are added when diegetic light already provides direction;
4. an embedded dossier/photo/screen is rendered with exactly the same medium as its host surface;
5. a major explosion is only a particle layer while the base render never yields;
6. the event override never returns to the base grammar;
7. explosion smoke defaults to smooth realistic volumetrics when the intended grammar is discrete graphic shape groups.
