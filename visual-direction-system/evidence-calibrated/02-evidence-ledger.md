## Promotion rule

A claim moves from `PROVISIONAL` to a stable knowledge-base rule only after:

1. support across multiple independent scene clusters or a deliberately narrow validated scope;
2. active search for counterexamples;
3. scope is defined (character / world / state / sequence / whole film);
4. production implication survives constraint reconstruction;
5. generative tests show the mechanism matters beyond palette/texture imitation.
