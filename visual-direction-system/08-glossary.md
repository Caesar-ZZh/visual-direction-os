# 08｜Glossary / Core Vocabulary

本页统一知识库中的核心术语。中文用于理解，英文用于跨团队沟通与检索。

| Term | 定义 |
|---|---|
| Primary Visual Variable | 角色或世界承担主要叙事工作的视觉维度 |
| Identity Anchor | 大幅风格变化中仍必须保留的识别锚点 |
| Controlled Range | 角色不是固定Look，而是在有规则的视觉范围内变化 |
| Coupled Variable Pair | 两个经常共同变化、共同承担角色语义的变量 |
| Character-relative Visual Semantics | 同一种视觉状态对不同角色可以具有不同意义 |
| Visual Ownership | 谁拥有并决定某个视觉变量 |
| Visual Authorship | 谁最终有权定义画面的组织规则 |
| Camera Allegiance | 摄影机在视觉上更服从角色、系统还是第三方 |
| Predictive Framing | 角色行动前，构图已经为其意图预留空间 |
| Visual Silence | 主动降低多个视觉轨道，为关键Beat释放注意力 |
| Visual Reserve | 为高潮预留尚未使用的强度、色彩、密度、运动或媒介能力 |
| Visual Debt | 为保持可读性而暂时压制的复杂度，可在后续偿还 |
| Sequence Score | 多个视觉参数随时间变化的轨道化设计 |
| Parameter Dominance Rotation | Primary保持稳定，但不同Secondary变量在不同Beat轮流领奏 |
| Visual Orchestration | Lead、Support、Silent变量之间的整体编排 |
| Visual Counterpoint | 不同变量故意表达不同甚至相反信息以产生潜台词 |
| Color Ownership | 某一颜色在叙事上属于角色、世界、关系、制度或记忆 |
| Color Territory | 某颜色占据的画面面积与空间控制范围 |
| Color Migration | 颜色从背景、物体等区域逐步靠近人物身份核心 |
| Color Contamination | 一个色域改变另一个色域，并可能产生关系色 |
| Color Residue | 重大事件后保留在新Baseline中的色彩痕迹 |
| Saturation Reserve | 为后续关键Beat保留饱和度变化空间 |
| Edge Script | Hard / Medium / Soft / Lost边缘的叙事使用规则 |
| Controlled Permeability | 人物主动决定自己与世界边界的渗透程度 |
| Fragmented Coherence | 局部碎裂或不一致，但整体Gesture与意图保持清楚 |
| Temporal Signature | 视觉变化进入时间的角色特有方式 |
| Multi-track Desynchronization | 不同视觉层以不同Cadence更新，但共享稳定身份锚点 |
| Readability Redundancy | 多个独立通道共同保证角色可识别性 |
| Readability Substitution | 一个识别通道失效时由另一个通道接管 |
| World Visual Grammar | 世界默认生成图像的Shape、Space、Value、Color、Edge、Medium、Density、Camera和Time规则 |
| Deviation Matrix | 衡量角色相对World Grammar在哪些维度偏离最多 |
| Nested Grammar | 角色属于世界的视觉词汇，但在少数变量上更极端 |
| Mechanism Similarity | 重建作品时底层视觉机制的相似程度 |
| Surface Similarity | 色板、材质、特效、造型等表层外观的相似程度 |

## 核心区分
Style不是一组标签，而是生成图像的规则。Character Visual Bible不是回答“长什么样”，而是回答“在压力下哪些变量变化、哪些不变、何时破例、最终谁获得控制权”。World Bible不是换Palette，而是定义不同Default Behaviors。Sequence不是镜头集合，而是参数随时间组织成的Visual Score。
