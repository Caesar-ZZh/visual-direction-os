# 07｜Original Case Study：Elian / Meridian

本案例用于验证系统的可迁移性：不使用Spider-Man、黑红、水彩或朋克拼贴，只保留生成机制。

## Character Thesis
Elian的核心问题不是移动自由，而是感知自主：**我是否有权决定什么值得被看见？**

Primary Variable：**Focus / Visibility**。

Stable Anchors：三角肩部轮廓、右眼附近单一浅色Mark、持续轻微前倾的Search Wedge姿态。

Coupled Pair：**Focus × Edge**。系统控制时，被指定对象获得Hard Edge与高对比；Agency阶段，Elian自己的视线和意图决定清晰度传播。

Temporal Signature：系统使用Snap Focus；Elian使用有方向的Pull Focus。

## World Thesis：Meridian
Meridian通过管理注意力维持秩序。世界的Primary Variable不是科技感，而是**Focal Hierarchy**。

世界采用漏斗式Shape Grammar，大量道路、建筑、灯光和标识向预定目标收束。几何空间可以很深，但感知深度被人为排序，因此 Geometric Depth ≠ Perceptual Depth。

低饱和蓝灰作为Base Field，Amber代表Assigned Attention。被压制区域不是单纯更暗或更破败，而是低对比、低纹理、低视觉优先级，即Visually Suppressed。

## Character–World Conflict
Elian与Meridian控制的是同一个变量，因此冲突属于**Ownership Conflict**：世界决定你看什么；角色争夺决定权。

关系变化：Harmonize → Resist → Destabilize → Rewrite。

## State Machine
Baseline：接受系统焦点。Curiosity：注意到系统没有突出显示的对象。Attention Conflict：人物视线与画面焦点分裂。Perceptual Crisis：错误的东西不断变清楚，角色无法确认注意力是否属于自己。Choice：停止试图看清一切，主动选择一个对象。Agency：清晰度沿自己的意图传播。Rewrite：被压制区域重新获得视觉存在。

## Sequence：The Unseen District
Narrative Verb：**REFOCUS**。

约2分钟的视觉结构：Assigned Vision → Forbidden Detail → System Correction → Perceptual Collapse → Visual Silence → Self-directed Focus → Rewrite。

关键不是让危机阶段增加无限物体，而是提高Focus Instability、降低Hierarchy可靠性。高潮前所有东西短暂失焦，形成Perceptual Silence；之后右眼Mark先清晰，再由角色主动把焦点拉向被压制区域。

Agency阶段的恢复顺序应是：Edge → Value Hierarchy → Texture → Color。先恢复“存在”，最后才恢复色彩，避免把价值表达误写成“变漂亮才值得看见”。

Amber最终从System Marker转变为Elian主动注意的标记，形成Color Ownership Transfer。

## Constraint Tests
禁止Blur和Depth of Field时，可用Contrast、Occlusion、Scale、Density和Framing继续表达Attention；禁止Amber时仍可通过Hierarchy工作；只用黑白时可通过Contrast Assignment工作；只看Motion时，可通过头部和身体从外部牵引转向主动锁定方向来表达Agency。

因此Elian不是“Blur Character”，而是**Attention Character**。

## Transfer Principle
Character Core保持不变，Expression随World改变。真正可迁移的是Primary Perceptual Variable与Ownership Arc，而不是具体效果。
