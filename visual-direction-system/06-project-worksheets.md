## D. Reverse Engineering Worksheet

固定输出：Narrative Verb、Primary Variable、Shape Map、Value Map、Color Function、Edge Map、Density Map、Direction Map、Negative Space、Camera Map、Medium Map、Read Order、Character–World Relation、State Position、Reusable Rule、Anti-Rule、Reconstruction Constraint。

## E. Constraint Reconstruction Test

依次进行：换角色 → 换世界 → 换色 → 换媒介 → 禁止全部表面特征。

评分时分开记录：Surface Similarity 与 Mechanism Similarity。目标不是前者高，而是后者高。

## F. Production QA

最终检查：Narrative Verb是否清楚；Primary Variable是否真的承担主要信息；Identity Anchor是否保留；Read Order是否正确；Surface是否覆盖Structure；状态是否符合State Machine；是否违反Anti-rule；若违反是否满足Break Condition；Sequence曲线是否连贯；Resolution是否形成新的Baseline而不是简单回到原点。
