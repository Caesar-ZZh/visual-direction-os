# 11｜Visual QA Checklist

## Narrative
- 当前镜头的Narrative Verb是否可以用一个动作词说清？
- 视觉变化是否来自角色状态，而不是单纯追求效果？
- 当前镜头在State Machine中的位置是否明确？

## Hierarchy
- 0.5秒内第一、第二、第三读取是否符合叙事优先级？
- 缩到约5cm或眯眼后，大形仍然成立吗？
- 背景细节是否抢夺Hero Readability？

## Character
- Stable Identity Anchor是否保留？
- Primary Variable是否仍是主要叙事通道？
- 一个识别通道失效时，是否有Readability Substitution？
- Character Range是否在有意义地扩张、收缩或恢复？

## World
- World Grammar是否清楚？
- 角色与世界当前是Harmonize、Amplify、Resist、Destabilize还是Rewrite？
- 世界的特殊性是否来自Default Behavior，而不只是Palette？

## Shape / Value / Edge
- Shape是否先于细节可读？
- 灰度下Hierarchy是否成立？
- Hard / Soft / Lost是否有叙事条件？
- Negative Space是否承担关系、路径、压力或呼吸功能？

## Color
- 每个重要颜色是否有Function与Owner？
- 最大Color Contrast属于真正重要的信息吗？
- 是否无意中消耗了Saturation Reserve？
- 颜色的Area、Duration、Frequency与Boundary是否符合当前Beat？
- 事件结束后是否需要Color Residue？

## Motion / Camera / Time
- Gesture是否形成强Temporary Graphic Design？
- Camera是否在正确角色或系统一侧？
- Camera是否应该Follow、Resist或Predict？
- Temporal Signature是否属于角色，而不是随机变化？
- Camera和角色是否同时过度混乱？若是，是否失去参照？

## Texture / Medium
- Texture是否仍被Value Family约束？
- Medium Behavior是否支持Narrative Mechanism？
- Surface Styling是否覆盖了Structure？

## Sequence
- 当前Beat的Lead、Support、Silent是否明确？
- 强度、组织度、Agency是否被误当成同一个参数？
- 高潮前是否保留Visual Reserve或Visual Silence？
- Climax是否发生Ownership Shift，而不只是Maximum Noise？

## Rules
- 是否违反Anti-rule？
- 若违反，是否满足Break Condition？
- Break之后如何Recovery？
- Resolution是否形成Baseline B，而不是简单返回Baseline A？

## Final Test
删除Color、Texture或标志性Surface FX后，核心机制是否仍然成立？如果不成立，回到Primary Variable、Hierarchy与Character–World Relationship重新设计。
