# 10｜Master Workflow：从Brief到Final Sequence的20步

1. 写Narrative Situation：发生什么，而不是画面长什么样。
2. 写Character State：人物现在处于什么心理位置。
3. 定义Viewer Response：观众第一时间应该感受到什么。
4. 压缩成一个Narrative Verb，例如CLAIM、WITHDRAW、DIVIDE、REFOCUS。
5. 找到角色最怕失去的能力或关系。
6. 将其映射成一个Primary Visual Variable。
7. 选择Secondary Variables，并明确哪些变量应该保持安静。
8. 定义至少三个Stable Identity Anchors与Readability Ladder。
9. 建立World Thesis和Primary World Variable。
10. 建立Character–World Compatibility：Harmonize / Amplify / Resist / Destabilize / Rewrite。
11. 建立Baseline、Pressure、Crisis、Decision、Agency、Resolution状态机及Transition Trigger。
12. 画3–7个大形的Composition Thumbnail，先验证Spatial Logic与Read Order。
13. 建Shape Map和2值/3值Value Map；必要时设置Contrast Budget。
14. 建Edge、Direction、Negative Space三张控制图，设计Attention Flow。
15. 建Color Function与Color Ownership，不先从色板审美出发。
16. 选择Medium Behavior，让材质行为支持Primary Variable。
17. 建Sequence Score，明确每个Beat的Lead、Support、Silent与Visual Reserve。
18. 设计Climax前的Visual Silence，并把真正高潮放在Decision、Ownership Transfer或不可逆变化上。
19. 做Constraint Reconstruction和Nine-variable Failure Test，确认系统不依赖表面标签。
20. 做Production QA，并把实际镜头反馈回Character/World Bible，形成Baseline B与Bible Update。

## 推荐交付物

项目开发过程中至少维护：Project Visual Thesis、Character Bible、World Bible、State Matrix、Sequence Score、Color Script、Reverse Engineering Sheet、Constraint Test、Anti-rules、Break Conditions、Production QA。

## 工作纪律

Structure before Surface。Value before Hue。Hierarchy before Texture。Mechanism before Medium。Sequence before Shot Polish。Rules before Rule-breaking。Agency before Spectacle。

## 最终判断标准

一个成熟系统应当做到：静帧可读、灰度可读、剪影可读、运动可读；状态变化有范围；世界变化不抹除角色；高潮不依赖单纯加法；风格被剥离后机制仍然成立；最终视觉变化能够回答“谁获得了定义画面的权力”。
