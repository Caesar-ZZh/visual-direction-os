# Narrative Visual Direction System

> A reusable knowledge base for character-specific visual storytelling, world grammar, sequence direction, color systems, visual production, and AI-assisted concept development.

## Core thesis

Visual style is not a collection of effects. It is a rule system that determines **what may change, when it may change, why it changes, and who owns that change**.

The complete framework:

```text
Narrative
→ Character Interpretation
→ Primary Visual Variable
→ Stable Identity Anchors
→ World Grammar
→ State Machine
→ Visual POV
→ Sequence Curves
→ Department Priority
→ Visual Beat
→ Agency / Resolution
```

## Three levels of use

### Analysis
Use the system to reverse-engineer existing films, animation, games, concept art, advertisements, and visual novels.

### Direction
Use the system to design character-specific visual behavior across states and sequences.

### Production
Use the system to create Visual Bibles, Color Scripts, Sequence Scores, prompts, concept art briefs, and QA criteria.

## Governing principles

- **Artist Intent > Passive Realism** — realism is not the highest-order rule when narrative clarity requires stylization.
- **Primary Variable First** — each character or world should have one dominant visual dimension.
- **Selective Deviation** — uniqueness comes from a few extreme dimensions, not making everything extreme.
- **Rule Before Break** — a rule must be established before breaking it can carry meaning.
- **Visual Reserve** — do not spend every visual resource before the climax.
- **Agency = Variable Ownership** — character growth becomes visual when the character begins controlling the variable previously controlled by the world, relationship, or system.
- **Baseline B, not Baseline A** — resolution should preserve evidence that the journey changed the visual system.

## Canonical character mechanism examples

- **Miles-type:** Space / Direction → agency means creating and owning paths.
- **Gwen-type:** Boundary / Edge → agency means selectively defining hard, soft, and lost boundaries.
- **Hobie-type:** Time / Medium → agency means choosing when to comply, synchronize, or remain inconsistent.
- **Elian-type:** Focus / Visibility → agency means choosing what deserves attention.

These are mechanism examples, not surface-style prescriptions.
