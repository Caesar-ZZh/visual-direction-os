# 01｜Master Framework

## Visual Direction is a rule system

A mature visual system defines not only appearance, but also defaults, variables, ranges, triggers, constraints, exceptions, and recovery states.

```text
Narrative
→ Character Interpretation
→ Primary Visual Variable
→ Identity Anchors
→ World Grammar
→ State
→ Sequence Curve
→ Visual Beat
→ Agency
→ Resolution
```

## Core rules

1. **Primary Variable First**: each character or world should have one dominant visual dimension.
2. **Stable Anchors**: changing styles need invariant identity information.
3. **Controlled Range**: character style is a range of allowed states, not one fixed look.
4. **Rule Before Break**: establish a baseline before violating it.
5. **Visual Reserve**: save contrast, saturation, camera energy, abstraction, density, or motion for later beats.
6. **Agency = Variable Ownership**: growth becomes visual when the character begins controlling the variable previously controlled by the world or system.
7. **Baseline B**: the ending should retain residue from the journey rather than simply return to the opening look.

## Psychological-to-visual mapping

| Narrative issue | Candidate visual variable |
|---|---|
| freedom / restraint | Space, Direction |
| intimacy / distance | Edge, Distance |
| identity | Shape, Medium, Time |
| order | Grid, Repetition |
| memory | Texture, Layer, Focus |
| visibility | Contrast, Focus, Framing |
| assimilation | Uniformity, Synchronization |
| decision | Direction clarity |
| emotional leakage | Color bleed |
| agency | ownership of the primary variable |

## State model

```text
BASELINE
→ PRESSURE
→ CRISIS
→ DECISION
→ AGENCY
→ RESOLUTION
```

For each state define: primary-variable range, supporting variables, camera relationship, readability strategy, and transition trigger.

## Organization vs intensity

High emotion does not require visual chaos. A useful matrix is:

| | Low organization | High organization |
|---|---|---|
| Low intensity | diffuse / numb | calm / stable |
| High intensity | collapse | decision / agency |

## Visual authorship

The deepest question is: **who controls the image-generating rules now?**

```text
WORLD / SYSTEM
→ CONFLICT
→ CHARACTER
```

## Master decision tree

```text
What is the narrative problem?
↓
What does the character fear losing?
↓
Which perceptual dimension represents that loss?
↓
Choose one Primary Variable
↓
Define 2–3 Identity Anchors
↓
Define the world baseline
↓
Define character–world compatibility
↓
Create the State Machine
↓
Define the crisis as failure of the character's visual rule
↓
Define agency as ownership transfer
↓
Create Sequence Curves
↓
Define Break Condition
↓

```
