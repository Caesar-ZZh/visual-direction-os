# 03｜World Visual Grammar

## World style is not palette + architecture

A world is defined by the default behavior of images inside it.

```text
World Visual Grammar
=
Shape Grammar
+ Spatial Grammar
+ Value Logic
+ Color Semantics
+ Edge Policy
+ Medium Behavior
+ Density Rules
+ Camera Behavior
+ Temporal Behavior
+ Character Compatibility
```

## World Bible fields

1. World Thesis
2. Primary World Variable
3. Shape Grammar
4. Spatial Grammar
5. Value Logic
6. Color Semantics

## World thesis before medium

Do not begin with “watercolor world,” “cyberpunk world,” or “gothic world.” Begin with a narrative function such as:

- reality is emotionally permeable;
- movement is highly regulated;
- space has accumulated through lived history;
- attention is institutionally governed.

Choose the medium only after defining what the world must do.

## World examples by mechanism

### Baseline navigable reality

Deep readable Z-space, strong architectural paths, hard/medium edges, stable time. The world gives a movement-driven character usable spatial infrastructure.

### Emotionally permeable reality

Physical description can dissolve, edge hierarchy can change, color fields may override physical lighting, and psychological distance can override geometric distance.

### Systematized reality

Large scale but controlled routes. Modular grids, structural repetition, harder edge policy, stable timing, and institutional color fields. Important principle: **large space does not necessarily mean freedom**.

### Accumulated high-density city

Layered infrastructure, vertical ecology, clustered density, strong large value families, and repeated discovery of additional depth layers. Complexity must be clustered rather than evenly distributed.

## Selective deviation

Character identity depends partly on difference from world baseline.

```text
Character Style
≈ Character Properties − World Baseline
```

Do not make every character deviate in every dimension. Assign a selective deviation budget. A character may be extreme in Time and Medium but largely obey world Shape and Camera rules.

## Character–World compatibility

Use four interaction modes:

- **Harmonize** — world supports the character mechanism.
- **Amplify** — world magnifies it.
- **Resist** — world constrains it.
- **Destabilize** — world causes the character's visual rule to fail.

Cross-world travel should create **visual mechanics collision**, not only background change.

## World transition model

```text
HOME GRAMMAR
→ CONTACT
→ CONTAMINATION
→ RULE CONFLICT
→ ADAPTATION
→ IDENTITY TEST
→ HYBRID / REJECTION
```

Useful principle: first change **how the character is rendered**, and only later change identity anchors.

A possible contamination order:

```text
Surface
→ Edge
→ Color
→ Lighting
→ Shape
→ Space
→ Time
```

Identity anchors should change last or not at all.

## Relational style

The same visual behavior can carry opposite meanings in different worlds. A stable clean rendering may mean calm for one character but institutional assimilation for another. Style is relational, not absolute.

## Hybrid residue

After leaving a foreign world, a character may retain acquired visual vocabulary. The target is not A→B→A but:

```text
Baseline A
→ Collision
→ Adaptation
→ Baseline B
```

The new baseline preserves identity while showing that the journey mattered.
